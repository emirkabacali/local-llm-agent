# 🤖 Local LLM Agent

A minimal **tool-calling AI agent** that runs entirely on your machine, powered by a local language model (**Qwen2.5-Coder 7B**) served through **Ollama**.

The goal of this project is to show the core tool-calling loop that frameworks like LangChain or CrewAI use under the hood — built from scratch, with **no agent framework**, in a single Python file.

## ✨ How It Works

```
 User request ──► LLM (Ollama) ──► JSON decision ──► Python runs the tool ──► Result
```

1. The user types a request in natural language (e.g. *"add 23 and 47"* or *"write a script that sums the even numbers from 1 to 10"*).
2. The model is given a system prompt describing the available tools and must answer **only** with a JSON object naming the tool and its arguments.
3. Python parses the JSON and calls the matching real function.
4. The result is printed back to the user.

If the model returns invalid JSON or an unknown tool name, the agent reports it instead of crashing.

## 🧰 Available Tools

| Tool | Description |
|------|-------------|
| `topla(a, b)` | Adds two numbers |
| `carp(a, b)` | Multiplies two numbers |
| `dosya_yaz(dosya_adi, icerik)` | Saves code generated by the model to a file |
| `yok` | No tool needed — the model answers directly |

> Function names and CLI prompts are currently in Turkish (`topla` = add, `carp` = multiply, `dosya_yaz` = write file).

## 🛠 Tech Stack

- **Python 3**
- **[Ollama](https://ollama.com)** — runs the LLM locally
- **Qwen2.5-Coder:7b** — open-source model optimized for coding tasks
- **requests** — talks to the Ollama REST API (`/api/generate`)

## 🚀 Getting Started

1. Install [Ollama](https://ollama.com).
2. Pull the model:
   ```bash
   ollama pull qwen2.5-coder:7b
   ```
3. Create a virtual environment and install dependencies:
   ```bash
   python -m venv venv
   venv\Scripts\activate        # Windows
   source venv/bin/activate     # macOS / Linux
   pip install requests
   ```
4. Run the agent:
   ```bash
   python ajan.py
   ```

## 💬 Example Session

```
=== Kodlama Ajanı ===
Sen: 23 ile 47'yi topla              # "add 23 and 47"
Ajan: Sonuç: 70                       # "Result: 70"

Sen: 1'den 10'a kadar çift sayıları toplayan bir script yaz, cift.py olarak kaydet
Ajan: cift.py dosyası oluşturuldu.    # "cift.py was created."
```

Type `çıkış`, `exit` or `quit` to leave.

## ⚠️ Limitations

- Tool selection relies on prompt instructions; smaller models sometimes return malformed JSON.
- `dosya_yaz` writes files without sandboxing or confirmation — run it only in a safe directory.
- Single-step only: the agent picks one tool per request and does not chain tool calls.
